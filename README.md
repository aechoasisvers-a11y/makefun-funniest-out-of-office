A single-line out-of-office auto-reply in which the inbox left in charge immediately starts negotiating for itself.

## Entry

> I'm out until Monday. I left my inbox in charge and it's already asking for a raise.

## Run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
